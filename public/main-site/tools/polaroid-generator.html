ให้รูปดิจิทัลดูเหมือนภาพ instant film

กรอบสีอ่อน พื้นที่ข้อความด้านล่าง และเกรนเล็กน้อยช่วยสร้างความรู้สึกแบบรูป instant film โดยไม่ต้องติดตั้งแอป คุณยังสามารถทำเวอร์ชันสะอาดสำหรับงานแบรนด์ หรือเพิ่มมุมเอียงและโทนอุ่นให้ดูเป็น scrapbook ได้

  • รูปท่องเที่ยวและรูปคาเฟ่
  • Instagram, Facebook และ Story
  • ภาพประกอบบล็อกและ newsletter
  • การ์ดความทรงจำและ scrapbook

ออกแบบให้เบราว์เซอร์ทำงานแทนเซิร์ฟเวอร์

เครื่องมือนี้ใช้ JavaScript และ Canvas 2D ฝั่งผู้ใช้ รูปที่เลือกไม่จำเป็นต้องถูกส่งไปยัง API จึงช่วยลดทั้ง latency, bandwidth, storage และความกังวลเรื่องข้อมูลส่วนบุคคล

สำหรับรูปจากมือถือขนาดใหญ่มาก ระบบจะลดขนาดสำเนาที่ใช้ทำงานในเบราว์เซอร์เพื่อควบคุมหน่วยความจำ ขณะที่ export ยังคงรองรับ PNG ความละเอียดสูง

เกี่ยวกับ Polaroid Generator

เครื่องทำรูปโพลารอยด์นี้ฟรีหรือไม่?

ฟรี ไม่มีลายน้ำ และไม่ต้องสมัครสมาชิก คุณสามารถสร้างและดาวน์โหลด PNG ได้จากเบราว์เซอร์

รูปของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ โค้ดเวอร์ชันนี้อ่านรูปและประมวลผลด้วย Canvas ในเบราว์เซอร์ จึงไม่จำเป็นต้องส่งไฟล์ภาพไปยังเซิร์ฟเวอร์ของ Siamese Cat Creative Club

รองรับรูปแบบไหน?

รองรับไฟล์รูปที่เบราว์เซอร์สมัยใหม่เปิดได้ เช่น JPG, PNG และ WebP และมีกรอบ Square, Portrait และ Wide

ใส่ข้อความภาษาไทยได้ไหม?

ได้ ระบบใช้ฟอนต์ที่มีอยู่บนอุปกรณ์และ fallback ที่รองรับภาษาไทย เมื่อเลือกสไตล์ที่ฟอนต์ลายมือไม่รองรับ ภาษาไทยจะ fallback ไปยังฟอนต์ระบบที่อ่านง่าย

ทำรูปแนว vintage ได้อย่างไร?

ลองเพิ่ม warmth เล็กน้อย ลด saturation หรือ contrast นิดหน่อย เพิ่ม fade และ film grain แล้วเปิด paper texture เพื่อให้ภาพดูนุ่มและย้อนยุคขึ้น

ทำไมรูปใหญ่จากมือถืออาจถูกย่อระหว่างแก้ไข?

ภาพถ่ายความละเอียดสูงใช้ RAM มากเมื่อถูกถอดรหัสเป็นพิกเซล ระบบจึงจำกัดสำเนาที่ใช้แก้ไขเพื่อให้ทำงานได้ดีบนมือถือ โดยยัง export ได้ในความละเอียดสูงตามขนาดงาน

ใช้ภาพที่สร้างไปทำงานเชิงพาณิชย์ได้ไหม?

ตัวเครื่องมือไม่เพิ่มข้อจำกัดใหม่ให้รูปของคุณ แต่สิทธิ์ใช้งานขึ้นอยู่กับสิทธิ์ของรูปต้นฉบับ โลโก้ ฟอนต์ หรือเนื้อหาอื่นที่คุณนำมาใช้ คุณควรใช้เฉพาะสิ่งที่คุณมีสิทธิ์ใช้งาน
