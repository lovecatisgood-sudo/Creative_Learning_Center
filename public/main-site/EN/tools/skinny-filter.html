FAQ

Questions about the online skinny filter

Does this tool upload my photo to a server?

No. The tool reads and edits the selected image in your browser. It does not send that photo to a Siamese Cat server. The page does download the MediaPipe runtime and AI model from a CDN/Google Storage so the AI can run on the device.

Does the skinny filter use AI?

Yes, but only a small pose-detection model to identify useful body landmarks such as the shoulders and hips. The actual reshape is a WebGL pixel warp, not a large generative image model.

Why can the background look bent?

This type of reshape moves pixels around the torso. Strong settings can affect nearby straight background lines. Lower the strength or effect area for a more natural result.

Does it work on phones?

It is designed for modern browsers with JavaScript and WebGL. AI speed depends on the device and browser. If AI detection cannot load, the manual focus mode still works.

Can this filter measure body weight or health?

No. It only changes the appearance of a photo for creative editing. It does not measure weight, health, body composition, or a person's real-world proportions.

Responsible use

Keep editing private and consensual

Use photos you own or have permission to edit. This is an adult portrait editor: do not use it on children’s photos. Your selected image stays in your browser; optional pose detection is processed on your device.
