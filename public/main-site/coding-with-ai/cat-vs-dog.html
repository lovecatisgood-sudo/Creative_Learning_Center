Siamese Cat vs Dog 1986

เกมอาร์เคดเรโทรสองภาษาที่รองรับมือถือ สร้างสำหรับเบราว์เซอร์ พร้อมตัวละคร ด่าน คะแนน เสียง และการควบคุมที่ตอบสนอง

เล่น Cat vs Dogดูวิธีสร้าง
เกมนี้คืออะไร

เกมอาร์เคดที่สมบูรณ์ ไม่ใช่แค่แบบฝึกเขียนโค้ด

ผู้เล่นบังคับแมววิเชียรมาศติดเจ็ตแพ็กผ่านฝูงสุนัขเอเลียนกลายพันธุ์ เกมรวมการเคลื่อนที่ การโจมตี การชน ไอเท็ม ระดับความยาก การผ่านด่าน การต่อสู้กับบอส การบันทึกคะแนน และผลตอบสนองต่อผู้เล่น

โจทย์ของเกมคือให้นักเรียนเห็นว่าเมื่อไอเดียสร้างสรรค์เล็ก ๆ เติบโตเป็นผลิตภัณฑ์ ระบบต่าง ๆ ต้องทำงานสอดคล้องกันทั้งบนโทรศัพท์และคอมพิวเตอร์ ในภาษาไทยและอังกฤษ

สร้างอย่างไร

เกมเบราว์เซอร์น้ำหนักเบาที่ไม่ใช้เฟรมเวิร์กเกม

การเขียนโปรแกรม
JavaScript แบบไม่ใช้เฟรมเวิร์กจัดการ game loop การควบคุม การเคลื่อนที่ การชน ศัตรู ด่าน คะแนน เสียง และสถานะที่บันทึกไว้
การแสดงผล
HTML5 Canvas วาดเกมแนวตั้งที่ปรับตามหน้าจอ ส่วน CSS ดูแลอินเทอร์เฟซรอบเกมและเลย์เอาต์มือถือ
เนื้อหา
พิกเซลอาร์ต ตัวละคร เรื่องราว เอฟเฟกต์เสียง และดนตรีต้นฉบับรองรับเวอร์ชันภาษาไทยและอังกฤษแยกกัน
ความสามารถของเบราว์เซอร์
การควบคุมแบบสัมผัสและพอยน์เตอร์ การปรับขนาดตามหน้าจอ localStorage, Web Audio, การจัดการเมื่อสลับหน้าจอ และ Web Share ช่วยให้เล่นได้โดยไม่ต้องติดตั้ง
กระบวนการใช้ AI แบบมีผู้สอน

แบ่งความซับซ้อนเป็นการตัดสินใจที่นักเรียนทดสอบได้

ผู้สอนช่วยให้โปรเจกต์มุ่งที่ระบบและหลักฐาน การใช้ AI ช่วยให้ร่างงานได้เร็วขึ้น แต่นักเรียนยังต้องเข้าใจกติกา เชื่อมต่อกับเกมอย่างปลอดภัย และทดสอบผลลัพธ์ระหว่างการเล่นจริง

  1. กำหนดประสบการณ์ผู้เล่นอธิบายการควบคุม ความท้าทาย ผลตอบสนอง และเงื่อนไขชนะหรือแพ้ก่อนลงมือเขียน
  2. ออกแบบสถานะเกมติดตามผู้เล่น ศัตรู กระสุน คะแนน พลังชีวิต ด่าน และระดับความยากเป็นข้อมูลที่ชัดเจน
  3. เชื่อมงานภาพกับกติกาทำให้สไปรต์ เสียง และเอฟเฟกต์ทุกชิ้นสื่อสารสิ่งที่ผู้เล่นจำเป็นต้องรู้
  4. ทดสอบบนอุปกรณ์จริงตรวจการสัมผัส การปรับขนาด เสียง ระดับความยาก ข้อความสองภาษา และการเล่นต่อเนื่อง แล้วแก้ที่สาเหตุของปัญหา
ทำไมจึงสร้างโปรเจกต์นี้

เพราะการทำเกมให้เสร็จสอนมากกว่าการสร้างโค้ด

โปรเจกต์นี้ต้องใช้การกำหนดทิศทางสร้างสรรค์ สถาปัตยกรรมระบบ การเขียนโปรแกรม การรวมแอสเซ็ต UX สองภาษา และการทดสอบซ้ำ จึงแสดงให้เห็นว่าแม้ AI ช่วยสร้างงานแต่ละส่วนได้ นักเรียนยังต้องมีวิจารณญาณและความพยายาม
