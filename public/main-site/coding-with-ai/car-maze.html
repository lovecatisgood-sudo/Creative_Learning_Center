Car Maze: Learn Python

เกมสองภาษาบนเบราว์เซอร์ที่เปลี่ยนคำสั่ง Python ให้เป็นการเคลื่อนไหวที่มองเห็นได้ ผ่าน 58 ภารกิจในโลกปริศนา 7 แห่ง

เล่น Car Mazeดูวิธีสร้าง
เกมนี้คืออะไร

บทเรียนเขียนโค้ดที่เล่นเหมือนเกม

ผู้เล่นสังเกตเส้นทาง เลือกเป้าหมาย และเขียนโปรแกรมขนาดเล็กเพื่อควบคุมรถ เมื่อรันโค้ด ผลลัพธ์จะปรากฏทันที ทำให้การเลี้ยวผิดเป็นสิ่งที่ย้อนดูและแก้ไขได้ ไม่ใช่ข้อผิดพลาดที่มองไม่เห็น

ภารกิจค่อย ๆ พัฒนาจากการเรียงคำสั่ง ไปสู่เงื่อนไข ลูป ฟังก์ชัน และการแก้ปัญหาที่ซับซ้อนขึ้น สภาพแวดล้อม Python ถูกจำกัดไว้เพื่อการเรียนรู้และความปลอดภัย ไม่ใช่ Python runtime สำหรับใช้งานทั่วไป

สร้างอย่างไร

หนึ่งโจทย์การเรียนรู้ หลายระบบที่ต้องทำงานร่วมกัน

ภาษาที่ใช้เรียน
คำสั่ง Python สำหรับการเคลื่อนที่ การตัดสินใจ การทำซ้ำ และฟังก์ชันที่นำกลับมาใช้ได้
ตัวแอปพลิเคชัน
อินเทอร์เฟซบนเบราว์เซอร์ด้วย React และ JavaScript มี execution worker แยก ระบบบันทึกความคืบหน้า และรองรับการติดตั้งแบบ PWA
ระบบเนื้อหา
58 ภารกิจใน 7 โลก พร้อมเป้าหมาย สิ่งกีดขวาง คำใบ้ การย้อนดู และคำอธิบายสองภาษา
การตรวจคุณภาพ
นักเรียนทดสอบทั้งคำตอบที่ถูกและผิด การกู้คืนความคืบหน้า สองภาษา หน้าจอมือถือ และขีดจำกัดการรันอย่างปลอดภัย โดยมีผู้สอนช่วยตรวจทาน
กระบวนการใช้ AI แบบมีผู้สอน

นักเรียนยังเป็นผู้รับผิดชอบการตัดสินใจ

AI สามารถเสนอหรือร่างงานชิ้นเล็กได้ แต่โปรเจกต์ยังต้องมีกติกาที่ชัด บริบทที่เพียงพอ การทดสอบ และการตัดสินใจของมนุษย์ว่าผลลัพธ์นั้นควรอยู่ในเกมหรือไม่

  1. กำหนดภารกิจระบุเป้าหมาย คำสั่งที่ใช้ได้ และเงื่อนไขความสำเร็จก่อนขอให้ AI ช่วย
  2. สร้างทีละระบบแยกการเคลื่อนที่ การรันโค้ด ข้อมูลภารกิจ คำใบ้ และความคืบหน้า เพื่อให้เข้าใจและตรวจสอบแต่ละส่วนได้
  3. รันและสังเกตเปรียบเทียบสิ่งที่โปรแกรมควรทำกับสิ่งที่รถทำจริง
  4. แก้บั๊กและอธิบายแก้ที่สาเหตุ ทดสอบภารกิจใกล้เคียงอีกครั้ง และอธิบายว่าเหตุใดการแก้ไขจึงได้ผล
ทำไมจึงสร้างโปรเจกต์นี้

เพราะโค้ดพูดคุยได้ง่ายขึ้นเมื่อเด็กเห็นมันทำงาน

Car Maze ทำให้การวางแผน การเรียงลำดับ และการแก้บั๊กมีโจทย์ใช้งานที่ชัดเจน และแสดงหลักสำคัญของคอร์สว่า AI อาจช่วยเขียนได้ แต่นักเรียนต้องกำหนดปัญหา ตัดสินผลลัพธ์ และปรับปรุงระบบเอง
